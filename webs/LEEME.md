# webs/

Cada negocio tiene su carpeta: `webs/<negocio>/`. Adentro quedan la auditoría (el antes), el brief, la web nueva (`index.html`), las fotos (`assets/`) y las capturas de revisión (`gate/`).

Para publicar se arrastra la carpeta del negocio a Netlify Drop. Claude te dice cuál y te deja una copia sin los archivos de trabajo.
